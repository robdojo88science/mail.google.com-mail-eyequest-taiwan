# EyeQuest email page

A standalone HTML copy of the EyeQuest email conversation, with a Gmail-style interface and Gmail favicon.

Open `index.html` directly, or visit the GitHub Pages site:

https://robdojo88science.github.io/mail.google.com-mail-eyequest-taiwan/

The page includes its display fonts and images. Drafts and interface actions affect this browser copy; the page does not sign in to Gmail or send email.

GitHub Pages publishes `main` from the repository root. No build step is required.
